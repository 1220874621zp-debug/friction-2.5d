# 命令面板：快速启动与帧命令

命令面板是一个 VS Code 风格的快速启动器。打开方式：菜单「帮助 → 命令面板」，或快捷键 **Ctrl+P**（可在 设置 → 快捷键 中修改，键名 `cmdPalette`）。

它有两种用法：**搜索执行菜单命令** 和 **直接输入命令语法操作场景**。

## 用法一：搜索执行菜单命令

输入文字后，面板按前缀匹配列出所有可用的菜单动作，回车执行第一条，或用方向键/鼠标选择。不想翻菜单找功能时用它最快。

小技巧：输入 `?` 可以列出**全部**可用动作（绕过前缀匹配）。

## 用法二：命令语法

在输入框直接输入以下语法（支持小数，逗号 `,` 会被当作小数点）：

### 跳转与步进

| 输入 | 作用 |
|------|------|
| `:12` | 跳到第 12 帧 |
| `:2s` | 跳到第 2 秒（按场景帧率换算） |
| `:1m` | 跳到第 1 分钟 |
| `+5` | 从当前帧前进 5 帧 |
| `-5` | 从当前帧后退 5 帧 |
| `+2s` / `-3m` | 前进 2 秒 / 后退 3 分钟（秒、分同样支持） |

### 变换选中图层

| 输入 | 作用 |
|------|------|
| `rotate:45` | 选中图层旋转 45 度 |
| `scale:2` | 选中图层缩放 2 倍 |
| `move:10x20` | 选中图层移动 x=10、y=20 |

### 入出点与标记

| 输入 | 作用 |
|------|------|
| `in:10` | 入点设为第 10 帧（支持 `s`/`m` 后缀） |
| `out:20` | 出点设为第 20 帧 |
| `marker:5` | 在第 5 帧打标记 |
| `marker:5 片段A` | 在第 5 帧打带标题「片段A」的标记 |
| `marker:5 A,10s B` | 一次打多个标记（逗号分隔，第 10 秒打 B） |

### 组合与历史

- 多条命令用 `&&` 串联，从左到右依次执行，例如：`:10 && rotate:45 && marker:10 起点`（先跳第 10 帧、再旋转选中图层、最后打标记）。
- 按 **↑** 键回溯历史命令，**Shift+↑** 把历史命令追加到当前输入后面拼接。

## 注意事项

- 跳帧、入出点、标记需要**已有活动场景**；变换命令作用于**当前选中的图层**，没有选中时无效果。
- 命令执行成功后面板自动关闭；语法不合法则保持打开，无提示。
- 需要循环、条件等更复杂的操作，请改用[脚本控制台](../scripting/script-console.md)。
