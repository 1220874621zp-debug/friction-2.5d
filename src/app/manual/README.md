# Friction 使用手册（内置文档源）

本目录是「帮助 → 使用手册」对话框的内容源，通过 `manual.qrc` 编进 exe，随软件分发、离线可用。

## 结构

```
manual/
├── INDEX.md        # 总索引：目录树的分组、顺序、文档显示名都由它决定
├── README.md       # 本维护说明（不进 qrc，不随软件分发）
├── manual.qrc      # 资源清单（新增文档必须登记，漏了 = 对话框里看不到）
└── <主题文件夹>/xxx.md
```

现有主题文件夹：

| 文件夹 | 内容 |
|--------|------|
| `basics/` | 基础操作（命令面板、通用工作流等） |
| `scripting/` | 脚本与自动化（脚本控制台、脚本 API 等） |

## 新增一篇文档

1. 把 md 文件放进对应主题文件夹（没有合适的就新建文件夹，文件夹名用英文）。
2. 在 `manual.qrc` 里加一行 `<file>主题文件夹/xxx.md</file>`。
3. 在 `INDEX.md` 对应小节下加一条 `- [显示名](主题文件夹/xxx.md)` 链接；
   不加的话文档会落入对话框里的「未收录」分组（能找到，但不在分类里）。
4. 重新编译 app 目标（qrc 变更会自动触发）。

## 约定

- 每篇 md 第一行写 `# 标题`（作为兜底显示名和搜索内容的一部分）。
- 支持标准 Markdown（标题 / 列表 / 表格 / 代码块），由 QTextDocument 的
  GitHub 方言渲染；不支持内嵌图片。
- 文档之间可以用相对链接互相引用（如 `[另一篇](../basics/xxx.md)`），
  对话框会解析到手册内对应页面。
- `INDEX.md` 里二级及以上的标题（`##`、`###`…）各生成一个目录分组，
  一级标题（`#`）是手册名，不生成分组。
- 手册正文用中文写（这是内容数据，不是 UI 字符串，不经过 tr()/翻译链）。
